## [1.0.0] - 2026-10-09
### Added
- First release of the TNTimer server plugin (Paper, Spigot, Bukkit, Purpur; Minecraft 1.8.8 - 26.3)
- Countdown above lit TNT (just the time, e.g. `3.4s`), coloured like the TNTimer mod
- Primed sulfur cubes on Minecraft 26.2+
- Text display labels on 1.19.4+, with `/tntimer toggle` per player; entity name tags on older servers
- `/tntimer reload` and `config.yml`
